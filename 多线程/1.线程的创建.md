# 线程的创建

## 通过函数指针创建

```cpp
void counter(int id, int numIterations)
{
	for (int i{0};i<numIterations;++i)
	{
		std::cout << "Counter " << id << " has value " << i << std::endl;
	}
}

std::thread t1{ counter,1,6 };
```

$thread$ 接受可变参数列表，第一个参数传入函数指针，后面的可作为函数的参数传入。

## 通过函数对象创建线程

```cpp
class Counter
{
public:
	Counter(int id,int numIterations)
		:m_id{id},m_numIterations{numIterations}
	{}

	void operator()()const
	{
		for (int i {0};i<m_numIterations;++i)
		{
			std::cout << "Counter " << m_id << " has value " << i << std::endl;
		}
	}

private:
	int m_id;
	int m_numIterations;
};

std::thread t1{ Counter{1,20} };

Counter c{ 2,12 };
std::thread t2{ c };

t1.join();
t2.join();
```

其实就是通过重载 ( ) 运算符实现

## 通过lambda 创建线程

其实上面的方法就是lambda 生成的类的实现方法

```cpp
int id{ 1 };
int numIterations{ 5 };

std::thread t1([id,numIterations]()
	{
		for (int i{0};i<numIterations;++i) std::cout << "Counter " << id << " has value " << i << std::endl;
		
	});

t1.join();
```

## 通过成员函数创建线程

```cpp
class Counter
{
public:
	Counter(int id,int numIterations)
		:m_id{id},m_numIterations{numIterations}
	{}

	void process() const
	{
		for (int i {0};i<m_numIterations;++i)
		{
			std::cout << "Counter " << m_id << " has value " << i << std::endl;
		}
	}

private:
	int m_id;
	int m_numIterations;
};

Counter req{ 1,10 };
std::thread t1(&Counter::process,&req);
t1.join();
```

使用这个方法需要注意数据争用的问题。

## 线程本地储存

$thread\_ local $ 修饰可以将任何变量标记为线程的本地数据，也就是会让每个线程都单独保存这个变量的独立副本。

```cpp
int k;
thread_local int n;

void threadFunction(int id)
{
	std::cout << std::format("Thread {} : k = {}, n = {}\n", id, k, n);
	++n;
	++k;
}

	std::thread t1{ threadFunction,1 };
	t1.join();
	std::thread t2{ threadFunction,2 };
	t2.join();
```

output：

```txt
Thread 1 : k = 0, n = 0
Thread 2 : k = 1, n = 0

```

并且如果 $thread\_ local $ 变量在函数作用域内声明，那么这个变量的行为和声明就和静态变量是一致的，只不过每个线程都有自己独立的副本，而且不论这个函数在线程重被调用多少次，每个线程仅初始化这个变量一次。

## 自动join线程

如果销毁了仍可以joinable 的线程实例，C++运行时会调用 std::terminate() 终止程序。C++20 引入了 std::jthread，同样定义在\<thread> ，jthread 比thread多了如下几个功能：

1. 在析构函数中自动join。
2. 支持所谓的协作式取消。被称为协作式取消，是因为支持取消的线程需要定期检查它是否需要取消自己。此时需要引入了两个关键类，他们定义在<stop_token>中。

1. std::stop_token：支持主动检查取消的请求。一个可取消线程需要定期在stop_token 上调用stop_requested() ，以确定是否需要停止他的工作。stop_token 可以和condition_variable_any 一起使用，这样线程在需要停止时就可以被唤醒。
2. std::stop_source：用于请求线程取消执行。通过调用stop_source上的request_stop() 方法来来完成。如果stop_source 被用于请求取消，那么该停止请求对所有相关的stop_source和stop_token 都可见。stop_requested() 方法可以用来检查是否已经请求了停止。

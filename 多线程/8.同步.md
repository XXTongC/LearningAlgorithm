# 同步

这部分内容都是基于 C++20 标准。

## 1. latch \<latch>

latch 是一次性使用的线程协调点。一旦给定数量的线程达到 latch 点时，所有线程都会解除阻塞并继续执行。基本上它是个计数器，在每个线程到达latch点的时候倒数。一旦计数器到达零，latch 将无限期保持在一个有信号的状态，所以阻塞线程都将解除阻塞，随后到达 latch 点的任何线程都会立刻被允许继续执行。

latch 的构造函数接收需要到达 latch 点的所需线程数。

* count_down：非阻塞成员函数，用于递减内部计数器。这个操作不会阻塞调用线程，因此线程可以继续执行其他任务。

* try_wait：这个成员函数用于测试内部计数器是否已经达到零。如果为零，表示所有线程都已经到达同步点，可以执行后续操作。这是一个非阻塞操作，因为它只是测试计数器的状态而不阻塞调用线程。

* wait：这是一个阻塞的成员函数，用于使调用线程等待，直到内部计数器达到零。当所有线程都已经到达同步点，调用 wait 的线程将被解除阻塞，可以继续执行后续操作。

* arrive_and_wait：这是一个组合操作，先递减计数器，然后阻塞线程等待计数器达到零，直到所有线程都到达同步点。这是最常用的，用于确保所有线程在继续执行之前都已经完成了特定的工作。

```cpp
std::mutex mux;
std::latch work_line{ 4 };

struct Job
{
	const std::string ID;
	void Initialize()
	{
		std::unique_lock lock{ mux };
		std::cout << ID << " is initializing...\n";
		// ... do initializing
	}
	Job(std::string id)
		:ID{id}
	{}
};

int main()
{
	Job jobs[]{ {"A"},{"B"},{"C"} ,{"D"} };
	std::vector<std::jthread> threads;
	auto work = [&](Job& job)
		{
			job.Initialize();
			work_line.arrive_and_wait();
			{
				std::unique_lock lock{ mux };
				std::cout << job.ID << " finished initialized\n";
			}
		};

	for (auto& t:jobs)
	{
		threads.emplace_back(std::jthread{ work,std::ref(t) });
	}

    // 主线程等待所有工作线程完成
    work_line.wait();
}
```

## 2. barrier \<barrier>

barrier 是由一系列阶段组成的可重用线程协调机制。许多线程在 barrier 点阻塞。当给定数量的线程到达 barrier 时，将执行完成阶段的回调，解除所有阻塞线程的阻塞，重制线程计数器，并开始下一个阶段。在每个阶段中，可以调整下一阶段的预期线程数。barrier 对于在循环之间执行同步非常有用。例如，假设有很多线程并发执行，并在下一个循环中执行一些计算。进一步假设一旦这些计算完成，需要在线程开始其循环的新迭代之前对结果进行一些处理。对于这些情况，设置 barrier 是完美的，所有的线程都会阻塞在 barrier处。当它们全部到达时，完成阶段的回调将处理线程的结果，然后解除所有线程的阻塞，以快开始它们的下一次迭代。

```cpp
constexpr explicit barrier(
    const ptrdiff_t _Expected, _Completion_function _Fn = _Completion_function()) noexcept
```

它主要有以下成员函数：

* arrive：用于将线程到达栅栏并减少预期计数。当线程调用 arrive 时，预期计数会减少。一旦所有线程都到达这个栅栏，预期计数归零，栅栏会打开，允许所有线程继续执行。

* wait：使线程在阶段同步点阻塞，直到当前阶段的完成步骤运行。一旦线程调用 wait 并在同步点阻塞，它将一直等待直到当前阶段完成，然后才能继续执行。

* arrive_and_wait：结合前两者，首先使线程到达栅栏并将预期计数减少一，然后在同步点阻塞，直到当前阶段完成。与 arrive 不同，arrive_and_wait 在到达后会立即阻塞。

* arrive_and_drop：不仅减少当前阶段的预期计数，还会减少后续阶段的初始预期计数。也就是说会影响未来阶段，可用于在某些情况下提前放弃等待。

## 2.1 latch 和 barrier 的比较

我们通过双向同步的例子来比较两者的用法：

### 2.1.1 latch

```cpp
#include <iostream>
#include <thread>
#include <latch>
#include <vector>
#include <mutex>

std::mutex mux;

void safe_print(const std::string& message)
{
	std::lock_guard<std::mutex> lock(mux);
	std::cout << message << std::endl;
}

void two_phase_worker(std::latch& phase1_latch, std::latch& phase2_latch,int id)
{
	// 第一阶段的工作
	safe_print("Worker " + std::to_string(id) + " performing phase 1");
	std::this_thread::sleep_for(std::chrono::milliseconds(200 * id));

	safe_print("Worker " + std::to_string(id) + " completed phase 1");

	// 第一阶段工作完成，计数减一并等待所有线程完成第一阶段
	phase1_latch.arrive_and_wait();

	// 所有线程同时开始第二阶段
	safe_print("Worker " + std::to_string(id) + " performing phase 2");
	std::this_thread::sleep_for(std::chrono::milliseconds(100 * (5 - id)));

	safe_print("Worker " + std::to_string(id) + " completed phase 2");
	
	// 第二阶段完成，计数减一
	phase2_latch.count_down();
}

int main()
{
	const int num_threads = 5;

	// 为两个阶段创建两个 latch
	std::latch phase1_latch(num_threads);
	std::latch phase2_latch(num_threads);

	std::vector<std::thread> threads;
	for (int i{0};i<num_threads;++i)
	{
		threads.emplace_back(two_phase_worker,
			std::ref(phase1_latch), 
			std::ref(phase2_latch), 
			i);
	}

	// 等待所有线程完成第二阶段
	phase2_latch.wait();

	std::cout << "Main thread: all workers completed both phases!\n";

	// 等待所有线程结束
	for (auto& t : threads) t.join();

	return 0;
}
```

### 2.1.2 barrier

```cpp
#include <barrier>
#include <iostream>
#include <thread>
#include <vector>
#include <mutex>

std::mutex mux;

void safe_print(const std::string& message)  noexcept
{
	try {
		std::lock_guard<std::mutex> lock(mux);
		std::cout << message << std::endl;
	}catch (...)
	{
		
	}
}

struct phase_completion
{
public:
	void operator()() const noexcept
	{
		try
		{
			std::lock_guard<std::mutex> lock(mux);
			std::cout << "All workers reached the barrier - moving to next phase" << std::endl;
		}
		catch (...)
		{

		}
	}

};
void two_phase_worker(std::barrier<phase_completion>& sync_barrier,int id)
{
	// 第一阶段的工作
	safe_print("Worker " + std::to_string(id) + " performing phase 1");
	std::this_thread::sleep_for(std::chrono::milliseconds(200 * id));

	safe_print("Worker " + std::to_string(id) + " completed phase 1");

	// 第一阶段工作完成，计数减一并等待所有线程完成第一阶段
	// 当所有线程到达屏障点时，屏障会自动重制
	sync_barrier.arrive_and_wait();

	// 所有线程同时开始第二阶段
	safe_print("Worker " + std::to_string(id) + " performing phase 2");
	std::this_thread::sleep_for(std::chrono::milliseconds(100 * (5 - id)));

	safe_print("Worker " + std::to_string(id) + " completed phase 2");
	
	// 第二阶段完成，计数减一
	sync_barrier.arrive_and_wait();
}


int main()
{
	const int num_threads = 5;

	// 创建一个barrier，指定参与同步的线程和完成动作
	std::barrier sync_barrier(num_threads, phase_completion{});

	safe_print("Main thread: starting " + std::to_string(num_threads) + " workers");

	std::vector<std::thread> threads;
	for (int i{0};i<num_threads;++i)
	{
		threads.emplace_back(two_phase_worker,
			std::ref(sync_barrier),
			i);
	}

	// 等待所有线程结束
	for (auto& t : threads) t.join();

	std::cout << "Main thread: all workers completed both phases!\n";

	return 0;
}
```

关于写 barrier 的例子时遇到一个小问题需要提一下，完成函数也就是构造函数的  _Completion_function _Fn = _Completion_function() 这个参数在 MSVC 是加强过的，并且在作为参数时是需要指定的，否则作为参数的 sync_barrier 的完成函数将是默认的，使得编译出现无法找到对应重载函数的错误。

```cpp
void two_phase_worker(std::barrier<phase_completion>& sync_barrier,int id)
```

## 3 semaphore（信号量）

semaphore 是轻量级同步语义，可用做其他同步机制（如 mutex、latch、barrier）的构建块。基本上一个 semaphore 由一个表示很多插槽的计数器组成。计数器在构造函数中初始化。如果获得了一个插槽，计数器将减少，而释放插槽将增加计数器。

\<semaphore> 中定义了两个 semaphore 类，分别是 std::counting_semaphore 和 std::binary_semaphore。

* acquire()
	
	递减计数器。当计数器为零时阻塞，直到计数器再次递增。

* try_acquire()

	尝试递减计数器，但如果计数器已经为零不会阻塞。如果计数器可以递减，则返回 ture，否则返回 false。

* try_acquire_for() 

	与 try_acquire 相同，但会在给定的时间段内尝试。

* try_acquire_until()

	与 try_acquire 相同，但是会一直尝试直到系统到达给定时间。

* release()

	计数器增加一个给定的数，并解除在 acquire 调用中线程的阻塞。

### 3.1 示例一 资源池管理：限制对有限资源的并发访问
```cpp
#include <iostream>
#include <thread>
#include <semaphore>
#include <vector>
#include <mutex>
#include <chrono>

class ResourcePool
{
private:
	std::counting_semaphore<10> pool_semaphore;
	std::mutex cout_mutex;

public:
	ResourcePool(int max_resources): pool_semaphore(max_resources){}

	void use_resource(int id)
	{
		// 获取资源
		pool_semaphore.acquire();
		{
			std::lock_guard lock(cout_mutex);
			std::cout << "Thread " << id << " acquired resources\n";
		}

		// 模拟使用资源
		std::this_thread::sleep_for(std::chrono::milliseconds(500 + id * 100));

		{
			std::lock_guard lock(cout_mutex);
			std::cout << "Thread " << id << " releasing resources\n";
		}

		pool_semaphore.release();
	}

};

int main()
{
	// 创建一个最多允许 3 个线程同时访问的资源池
	ResourcePool pool(3);

	// 创建 8 个线程尝试使用资源
	std::vector<std::thread> threads;
	for (int i {0};i<8;++i)
	{
		threads.emplace_back([&pool,i]()
			{
				pool.use_resource(i);
			});
	}

	for (auto& t : threads) t.join();
}
```

### 3.2 示例二 模拟生产者-消费者模型

```cpp
#include <iostream>
#include <thread>
#include <semaphore>
#include <mutex>
#include <chrono>
#include <queue>
#include <random>
#include <queue>

template<class T>
class BoundedBuffer
{
private:
	std::mutex mutex;
	std::queue<T> buffer;
	const size_t capacity;

	// 空槽位的数量（生产者可生产数量）
	std::counting_semaphore<> empty_slots;

	// 满槽位的数量（消费者可消费数量）
	std::counting_semaphore<> filled_slots;

public:
	explicit BoundedBuffer(size_t size)
		:capacity(size),empty_slots(size),filled_slots(0)
	{}

	void produce(T item)
	{
		empty_slots.acquire();

		{
			std::lock_guard lock(mutex);
			buffer.push(item);
			std::cout << "Produced: " << item << ", buffer size: " << buffer.size() << std::endl;
		}

		// 通知有新数据可消费
		filled_slots.release();
	}

	T consume()
	{
		// 等待有数据可消费
		filled_slots.acquire();

		T item;

		{
			std::lock_guard lock(mutex);
			item = buffer.front();
			buffer.pop();
			std::cout << "Consumed: " << item << ", buffer size: " << buffer.size() << std::endl;
		}

		// 通知有新的空槽位
		empty_slots.release();

		return item;
	}

};

int main()
{
	// 创建容量为 5 的缓冲区
	BoundedBuffer<int> buffer(5);

	// 生产者线程
	std::thread producer([&buffer]
		{
			std::random_device rd;
			std::mt19937 gen(rd());
			std::uniform_int_distribution<> distribution(1, 100);

			for (int i{0};i<20;++i)
			{
				int value = distribution(gen);
				buffer.produce(value);
				std::this_thread::sleep_for(std::chrono::milliseconds(100));
			}

		});

	// 消费者线程
	std::thread consumer([&buffer]
		{
			for (int i{ 0 }; i < 20; ++i)
			{
				int value = buffer.consume();
				std::this_thread::sleep_for(std::chrono::milliseconds(200));
			}
		
		});

	producer.join();
	consumer.join();
}
```

### 3.3 线程同步与屏障（静态条件讨论）

```cpp
#include <iostream>
#include <thread>
#include <semaphore>
#include <vector>
#include <mutex>
#include <atomic>


std::mutex mux;
class SemaphoreBarrier
{
private:
	std::mutex cout_mutex;
	std::atomic<int> count;
	const int num_threads;
	std::counting_semaphore<> turnstile1;
	std::counting_semaphore<> turnstile2;

public:
	explicit SemaphoreBarrier(int n):
		count(0),
		num_threads(n),
		turnstile1(0),
		turnstile2(0)
	{}

	void wait()
	{
		// 第一个栅栏
		if (++count == num_threads)
		{
			// 最后一个线程到达，打开第一个栅栏
			turnstile1.release(num_threads);
			{
				std::lock_guard lock(cout_mutex);
				std::cout << "First turnstile released\n";
			}
			
		}

		// 等待第二个栅栏打开
		turnstile1.acquire();

		// 第二个栅栏
		if (--count==0)
		{
			// 最后一个线程通过，打开第二个栅栏
			turnstile2.release(num_threads);
			{
				std::lock_guard lock(cout_mutex);
				std::cout << "Second turnstile released\n";
			}
		}

		// 等待第二个栅栏打开
		turnstile2.acquire();
	}

};

void worker(SemaphoreBarrier& barrier, int id)
{
	// 第一阶段工作
	{
		std::lock_guard<std::mutex> lock(mux);
		std::cout << "Worker " << id << " performing phase 1\n";
	}
	// 模拟第一阶段工作
	std::this_thread::sleep_for(std::chrono::milliseconds(200 * id));

	// 等待所有线程完成第一阶段
	barrier.wait();

	// 第二阶段工作
	{
		std::lock_guard<std::mutex> lock(mux);
		std::cout << "Worker " << id << " performing phase 2\n";
	}

}

int main()
{
	const int num_threads = 5;

	// 创建一个信号量屏障
	SemaphoreBarrier barrier(num_threads);

	std::vector<std::thread> threads;
	for (int i {0};i<num_threads;++i)
	{
		threads.emplace_back(worker, std::ref(barrier), i);
	}

	for (auto& t : threads) t.join();
}
```

这里简单讨论一下竞态条件的问题：如果我们将 wait() 函数更改如下：

```cpp
void wait()
{
	// 栅栏
	if (++count == num_threads)
	{
		// 最后一个线程到达，打开第栅栏
		turnstile1.release(num_threads);
		count = 0;
		{
			std::lock_guard lock(cout_mutex);
			std::cout << "First turnstile released\n";
		}
			
	}

	// 等待栅栏打开
	turnstile1.acquire();
}
```

考虑如下情景：

1. 所有线程到达栅栏，最后一个线程将 count 增加到 num_threads
2. 最后一个线程释放信号量，唤醒所有等待的线程
3. 所有线程继续执行，并很快完成下一阶段的工作
4. 一些快速的线程再次到达 wait() 函数，开始新一轮的同步
5. **问题出现**：如果快速线程在慢速线程重制 count 之前就增加了 count，那么 count 的值将不正确

这种情况将可能会导致：

* 计数器值不准确

* 栅栏可能永远不会打开（死锁）

* 栅栏可能过早打开（同步失败）

而双栅栏正好可以解决这个问题，下面解释一下它的工作原理：

#### 第一阶段

1. 线程到达并增加计数器
2. 最后一个线程打开第一个栅栏
3. 所有线程通过第一个栅栏

#### 第二阶段

1. 线程到达并增加计数器
2. 最后一个线程（计数器归零）打开第二个栅栏
3. 所有线程通过第二个栅栏

### 3.4 限流器

使用令牌桶的算法实现的限流器：以固定速率向桶中添加令牌，执行操作需要消耗令牌。

```cpp
#include <iostream>
#include <thread>
#include <semaphore>
#include <vector>
#include <mutex>
#include <chrono>

std::mutex mux;
class RateLimiter
{
private:
	std::counting_semaphore<> tokens;
	std::thread token_generator;
	std::mutex cout_mutex;
	bool running;

	void generate_tokens()
	{
		while (running)
		{
			// 每隔一段时间添加一个令牌
			std::this_thread::sleep_for(std::chrono::milliseconds(100));
			tokens.release();

			{
				std::lock_guard<std::mutex> lock(cout_mutex);
				std::cout << "Token added\n";
			}
		}
	}

public:
	explicit RateLimiter(int initial_tokens) :
		tokens(initial_tokens),
		running(true)
	{
		// 启动令牌的生成线程
		token_generator = std::thread([this]
			{
				generate_tokens();
			});
	}

	~RateLimiter()
	{
		running = false;
		if (token_generator.joinable())
		{
			token_generator.join();
		}
	}

	void acquire()
	{
		tokens.acquire();
	}

};

void perform_operation(RateLimiter& limiter,int id)
{
	for (int i{0};i<5;++i)
	{
		// 获取令牌
		limiter.acquire();

		// 执行操作
		{
			std::lock_guard<std::mutex> lock(mux);
			std::cout << "Thread " << id << " performing operation " << i << std::endl;
		}
	}
}

int main()
{
	// 创建一个初始有 2 个令牌的限流器
	RateLimiter limiter(2);

	// 创建多个线程尝试执行操作
	std::vector<std::thread> threads;
	for (int i{0};i<3;++i)
	{
		threads.emplace_back(perform_operation, std::ref(limiter), i);
	}

	for (auto& t : threads) t.join();
}
```

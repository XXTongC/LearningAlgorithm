# 线程的返回值

根据之前的内容，我们可以通过 std::thread 启动一个新的线程，计算并得到一个结果，当线程结束执行时不容易取回计算的结果。另一个与其相关的问题是处理异常的错误。如果线程抛出一个异常，而这个异常没用被线程本身处理，C++运行时将调用 std::terminate()，这会导致终止整个程序

## future 与 promise

C++11提供了 future 与 promise 类，可以解决上述关于线程返回值接收的问题。对于 std::future 就如它的翻译一样这是一个 “未来” 会有用的值，也就是它是**接收端**。而对于 std::promise 是用于设置将来会被 std::future 读取的值，也就是说线程通过它发送异步操作的结果，是**发送端**。

但是这里有一些需要注意的问题：

1. 对 std::future 调用 get() 取出结果，并保持在对应变量中。如果另一个线程尚未计算完结果，对 get() 的调用将阻塞，直到该结果值可用。并且只能调用一次，第二次调用 get() 是UB行为。
2. 对 std::promise 调用 set_value() 来储存结果，也可调用 set_exception() 储存异常。只能在特定的 promise 上调用一次 set_value() 或 set_exception()。多次调用将抛出 std::future_error 异常。

以下是使用 std::future 和 std::promise 的一个简单示例：

```cpp
#include <iostream>
#include <future>
#include <thread>

void doWork(std::promise<int> thePromise)
{
	//	... do some work ...
	// And ultimately store the result in the promise
	thePromise.set_value(42);
}

int main()
{
	// Create a promise to pass to the thread
	std::promise<int> myPromise;

	// Get the future of promise
	std::future theFuture{ myPromise.get_future() };

	// Create a thread and move the promise into it
	std::thread theThread{ doWork,std::move(myPromise) };

	// Get the result
	int result{ theFuture.get() };
	std::cout << "Result: " << result << std::endl;

	// Make sure to join the thread
	theThread.join();
}
```

也可以获取异常：

```cpp
#include <iostream>
#include <future>
#include <thread>

void producer(std::promise<int> promise)
{
	try
	{
		// 模拟计算出错
		throw std::runtime_error("Computation failed");
	}
	catch (...)
	{
		promise.set_exception(std::current_exception());
	}
}

int main()
{
	std::promise<int> promise;
	std::future<int> future = promise.get_future();

	std::thread producer_thread(producer, std::move(promise));

	try
	{
		int value = future.get();
		std::cout << "Value: " << value << std::endl;
	}catch (const std::exception& e)
	{
		std::cout << "Exception caught: " << e.what() << std::endl;
	}

	producer_thread.join();
}
```

### 关于 future 的状态和操作

#### 状态

一个 std::future 对象可以处于以下三种状态之一：

1. 未就绪（Deferred）：异步操作尚未开始
2. 就绪（Ready）：异步操作已完成，结果可用
3. 无效（Invalid）：future 对象没用关联的共享状态

## std::packaged_task

std::packaged_task 将一个可调用对象与一个 std::future 关联起来。当这个可调用对象被执行时，其结果会被储存在与 std::future 关联的共享状态中，可以通过 future 对象异步获取这个结果，如此就不需要显式地使用 std::promise。

其主要特点有：

1. 异步执行：可以在一个线程中创建任务，在另一个线程中执行，并在需要时获取结果。
2. 结果传递：通过 std::future 安全地在线程间传递结果或异常。
3. 延迟执行：可以创建任务但不立即执行，等到需要时再调用。
4. 异常处理：如果封装的函数抛出异常，该异常会被捕获并储存，可以通过 future 的 get() 方法重新抛出。

```cpp
#include <iostream>
#include <future>
#include <thread>

int calculateSum(int a,int b)
{
	return a + b;
}

int main()
{
	std::packaged_task<int(int, int)> task{ calculateSum };

	auto theFuture{ task.get_future() };

	std::thread theThread{ std::move(task),39,3 };

	int res = theFuture.get();

	std::cout << res << std::endl;

	theThread.join();
}
```

当然也可写为：

```cpp
std::packaged_task<int(int, int)> task{[](int a,int b)
{
	return a + b;
}};
```

## std::async

std::async 可用于启动一个异步任务，它接受一个可调用对象和该可调用对象的参数，然后返回一个 std::future 对象，该对象最终将包含异步操作的结果。

async() 可通过两种方法运行函数：

* 创建一个新的线程，异步运行提供的函数。

* 在返回的 future 上调用 get() 方法时，在主线程上同步地运行函数。

std::async 有三个调用地策略参数，如下：

* launch::async：强制C++运行时在一个不同的线程上异步地执行函数。

* launch::deferred：强制C++运行时在调用 get() 时，在主线程上同步地执行函数。

* launch::async | launch::deferred：允许 C++ 运行时进行选择（=默认参数）

```cpp
#include <iostream>
#include <future>

int calculateSum(int a,int b)
{
	return a + b;
}

int main()
{
	std::future<int> t;
	
	auto myFuture{ std::async(calculateSum,10,2) };
	//auto myFuture{ std::async(std::launch::async,calculateSum,10,2) };
	//auto myFuture{ std::async(std::launch::deferred,calculateSum,10,2) };

	int result{ myFuture.get()};
	std::cout << result << "\n";
}
```

但使用 async 需要注意以下问题：

1. 阻塞问题：默认情况下，如果 std::future 在析构时任务尚未完成，析构函数会阻塞等待任务完成。
2. 线程资源：过度使用 std::async 可能导致线程资源耗尽，特别是在使用 std::launch::async 策略时。
3. 执行策略：默认策略（std::launch::async | std::launch::deferred）可能导致任务不一定在单独地线程中执行，这可能不符合预期。
4. 异常处理：任务中未捕获地异常会被储存在 future 中，并在调用 get() 时重新抛出。
5. 线程安全：需要确保传递给 std::async 的函数和数据是线程安全的。

## 异常处理

使用 std::future 的一大优点就是它们会自动在线程之间传递异常。在 future 上调用 get() 时，要么返回计算结果，要么重新抛出与 future 关联的 promise 中储存的任何异常。使用 packaged_task 或 async() 时，从以启动的函数抛出的任何异常将自动储存在 promise 中。如果将 std::promise 用作 promise ，可调用 set_exception() 以在其中储存异常。

## std::shared_future

std::future< T > 只要求 T 可移动构造，所以调用其 get() 时，结果会被移出 future ，并返回给你。所以 future< T > 只能调用 get() 一次。

如果要多次调用 get()，甚至从多个线程多次调用，那么就需要使用 std::shared_future< T >，此时 T 需要可复制构造。所以我们可以使用 std::future::share()，或给 std::shared_future 构造函数传递 future，以创建 shared_future。注意 future 不可复制所以需要移动它。

shared_future 可用于同时唤醒多个线程，也就是在C++20之前实现线程同步的一种方式，如下例：

```cpp
#include <iostream>
#include <future>

int main()
{
	{
		std::promise<void> thread1Started, thread2Started;

		std::promise<int> signalPromise;
		std::shared_future<int> signalFuture{ signalPromise.get_future().share() };
		//std::shared_future<int> signalFuture{ signalPromise.get_future() };

		auto function1{ [&thread1Started,signalFuture]
		{
			thread1Started.set_value();
			int parameter{ signalFuture.get() };
			// ...
			std::cout << "function 1 started\n";
		} };

		auto function2{ [&thread2Started,signalFuture]
		{
			thread2Started.set_value();
			int parameter{ signalFuture.get() };

			std::cout << "function 2 started\n";


		} };

		std::future result1{ std::async(std::launch::async,function1) };
		std::future result2{ std::async(std::launch::async,function2) };

		thread1Started.get_future().wait();
		thread2Started.get_future().wait();

		signalPromise.set_value(42);
	}
}
```

关于以上代码这里对其执行流程进行一个解释：

1. 主线程创建所有 promise 和 future 对象
2. 主线程启动两个工作线程
3. 主线程会在调用 threadXStarted.get_future().wait() 后阻塞并等待工作线程的通知
4. 工作线程启动以后，会调用 threadXStarted.set_value() 以通知主线程可以继续，之后调用 signalPromise.get() 并阻塞等待主线程发送继续执行的信号
5. 主线程在收到两个工作线程均启动的通知后，调用 signalPromise.set_value 以发送信号通知工作线程可以继续
